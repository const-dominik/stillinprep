## Prerequisites
Node ^20

## Running

1. `git clone https://github.com/const-dominik/stillinprep-front.git`
2. `npm install`
3. `npm run dev`

App should be launched at [http://localhost:3000](http://localhost:3000).

## Testing

### Unit
Run tests using `npm run unit`.

Check test coverage with `npx jest --coverage`.

### E2E
Run tests using `npm run e2e`.

### All

Run unit and e2e tests with `npm run test`.
